# Receiving-network artwork

Local SVG assets for Bitcoin, Ethereum, Solana, TRON and XRP receiving-address rows. [network-icons.ts](../network-icons.ts) maps the application presets to these files.

Artwork is from [atomiclabs/cryptocurrency-icons](https://github.com/atomiclabs/cryptocurrency-icons), version 0.18.1, licensed under [CC0-1.0](LICENSE.txt). Assets are served locally; displaying an icon does not request a remote image.
