## Native indexer verification

[Indexer evidence](../../deployments/testnet-p2-indexer.json): bootstrap at ledger **13472891**, hash `C559146FC4F3E0D2E715D8D61054DD7E8770240D9C15E84ABBD56E6FCF97C57B`. Its 95 namespace entries and 19 claimed owners matched independent pinned RPC/SDK reads. The snapshot was taken during the temporary lifecycle; final cleanup is a later ledger.

Replay processed every transaction in **51 contiguous ledgers**, through **13472942**, including **225 transactions** and **71 events**. Final state matches the independent 88-entry namespace and contains 18 projected domains; both temporary domains are absent. Actual ledger-close subscription and re-subscription after disconnect passed. SQLite reopening retains all 71 unique outbox IDs and the last cursor, with no redelivery after that cursor.

Bootstrap used **83 full-ledger pages**. An initial 12-second RPC timeout interrupted an earlier attempt. The completed bootstrap subsequently hit a 15-second SDK owner-read deadline; owner comparison resumed from stored SQLite, with explicit connection setup, 30-second read budgets and concurrency two. It did not rescan the ledger. These observations demonstrate public-RPC startup cost, not production capacity. The implementation still holds materialized projection in RAM.

### Bootstrap transport recovery follow-up

The source now retries a pinned bootstrap read up to twice on typed timeout/disconnection errors, preserving its exact hash and page marker. A recovered timeout on page two does not repeat page one. Reconnection rechecks the network; semantic RPC errors, changed networks and invalid responses still fail closed. Exhausting the retry budget leaves SQLite without a committed partial checkpoint. Operators can set a 0–5 retry budget and initial backoff through `LedgerSourceOptions`; zero disables retries.

Four additional deterministic transport tests cover page preservation, bounded exhaustion with SQLite, RPC/network failures and successful reconnect/disabled retries. All 47 indexer tests pass. These are mocked transport tests, separate from the earlier native bootstrap evidence. The change reduces restarts caused by temporary RPC failures; it does not reduce the full-ledger page count or implement persistent scan resume.

No isolated `xahaud` executable was found in the checked local/WSL environment, and the Docker Linux daemon was unavailable during this follow-up. Native weak-failure and emit/callback injection were not run. The existing shared testnet treasury was not modified to force a failure.

Still open: native weak-phase fault injection (F-01), real failed/expired emit/refund and stale callback replay, exhaustive fee/reserve combinations, wallet-provider/mobile consent behavior, million-domain memory/load tests, retention and deployment-version migration. This bounded replay is not a genesis-to-head historical backfill certification. See [findings](FINDINGS.md).
