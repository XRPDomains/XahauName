## Recovered deployment defect

The first installation used an incorrect all-ones emission mask. Its initial purchase rejected with code 60; payment/state rolled back and only fee was charged. Effective installed permissions were corrected in an intermediate SetHook. The final upgrade additionally aligns native label validation with the ASCII SDK policy and checks unpause deletion failures. Issuance now permits only Payment, Mint and CreateSellOffer. The failed receipt remains in the validation summary. The final artifact was tested from the beginning with two fresh wallets; all submissions succeeded. Raw invalid-name and idempotent-unpause simulations also passed. The complete namespace returned to its original 62 entries with byte-for-byte matching data.

## Remaining limits

Testnet release, not an independent production security audit. Treasury upgrade/reset/issuer-burn authority remains. Fifteen addresses/texts,128-byte values, uint16 coin IDs, shared namespace and legacy auxiliary-key layouts remain bounded; million-domain scale is unproven. Content URI and avatar are supported subsets, not full ENS ABI/ENSIP compatibility. Failed refunds can need operator recovery. Frontend production build/ZIP was not generated; real wallet approval on a public HTTPS origin still needs manual acceptance testing.
